Over Mij

Ik ben een 23-jarige software developer uit Lelystad en ben recent afgestudeerd aan het MBO College Almere. Mijn passie voor programmeren begon tijdens mijn eerste mbo-opleiding, Expert IT Systems and Devices. Tijdens deze opleiding ontwikkelde ik met Python een consoleapplicatie waarmee gebruikers persoonlijke gegevens konden opslaan in een MySQL-database. Door dit project ontdekte ik hoe leuk ik het vind om software te bouwen en groeide mijn interesse in programmeren. Dit motiveerde mij om de opleiding Software Development te volgen.

Ik ben van nature nieuwsgierig en vind het interessant om uit te zoeken hoe verschillende onderdelen van een applicatie samenwerken en hoe complexe ideeën gerealiseerd worden als werkende complete applicatie. Daarnaast geeft het mij voldoening om een idee stap voor stap uit te werken tot een volledig functionerende applicatie. Het proces van niets naar iets bouwen is voor mij één van de mooiste aspecten van softwareontwikkeling en motiveert mij om mezelf continu te blijven ontwikkelen.

Tijdens mijn opleiding heb ik verschillende applicaties ontwikkeld, waaronder een analysedashboard, een dashboard voor voorraadbeheer, een Yahtzee-applicatie, een Kanbanbord en diverse websites met WordPress. Bij elk project hebt ik nieuwe technieken geleerd en mijzelf verder ontwikkeld als software developer.
